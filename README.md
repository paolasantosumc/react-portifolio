# Portfólio Paola Santos — React

Projeto convertido para React com Vite. O projeto visa apresentar os dados sobre a "Paola".

## Requisitos
- Node.js 18 ou superior
- npm

## Como executar
```bash
npm install
npm run dev
```

## Gerar versão de produção
```bash
npm run build
npm run preview
```
